One traceable analytical flow

ERP, MES, WMS, supplier and logistics sources → raw ingestion → staging → validation and quarantine → curated star schema → SQLite warehouse → analytics, forecasting and inventory projection → exception engine → Power BI-ready exports and FastAPI.

  • Six business domains: demand, inventory, suppliers, orders, logistics and facilities.
  • Fixed-seed generation and controlled defects with auditable rejection reasons.
  • Moving-average baseline versus trend/seasonal regression, selected per product using chronological validation.
  • Structured analytics assistant with a deterministic fallback; no credentials required.
  • Complete six-page Power BI specification, CSV exports, DAX and import assets.
